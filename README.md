**Selenium Automation Scripts**
- This repository contains automation scripts created for practice using Selenium WebDriver with JavaScript.

**Features**
1. Automates web browser tasks such as navigation, form filling, and interactions
2. Designed for learning and experimentation with Selenium WebDriver
3. Scripts are modular and easy to modify

**Technologies Used**
JavaScript – Programming language for scripting

Selenium WebDriver – Browser automation framework

Node.js – Runtime environment for running the scripts
